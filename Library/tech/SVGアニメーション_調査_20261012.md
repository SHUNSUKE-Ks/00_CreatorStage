## 1. 作り方の比較

| 方式 | Android Chrome での重さ | iPad Safari | 動きを減らす設定 |
|---|---|---|---|
| CSS（transform・opacity） | とても軽い（GPU が効きやすい） | 対応 | `@media (prefers-reduced-motion: reduce)` で止められる |
| Web Animations API | 軽い（ブラウザの中で動く） | 対応 | JS で matchMedia を見て時間を0に |
| SMIL（`<animate>`） | ふつう（複雑だと重い） | 対応（将来の互換に注意） | まとめて止めにくい |
| JS ライブラリ | やや重い（ライブラリの分） | 広く対応 | ライブラリの設定で |

## 3. ガジェット風 UI の見本（報告）

- Chrome Knob（CodePen・Tom Hermans）：クロームのつまみ。CodePen の利用規約（商用は個別に確かめる）
- react-dial-knob（GitHub、MIT）：マウス・指・キー対応のつまみ。React なので考え方だけ借りる
- CodePen の knob のタグ：つまみの例が多い。ライセンスは Pen ごと

## 4. 操作（上下に引いて回す・キー）とアクセシビリティ

- `role="slider"`・`tabIndex=0`・`aria-valuemin/max/now`・`aria-label`
- pointerdown → pointermove（上に引くとプラス）→ pointerup。`touch-action: none`
- ↑→ で増やす、↓← で減らす
- 値 0〜100 を −135°〜+135° に直して `<g transform="rotate(...)">` だけ変える

## 5. 重くしないこつ

- filter（ぼかし・光）の代わりに、透明度を変えた同じ形を重ねる・グラデーションで立体感
- 動く `<g>` にだけ、動いている間だけ `will-change: transform`
- 形（`d`）を作り直さず、transform の数だけ変える

## 6. 最初に試す3つ（報告）

1. CSS（transform・opacity）＋素の SVG
2. 自作の Pointer Events（上下に引く・キー）
3. filter を使わず、グラデーションと重ねた形で立体感
